## Project Overview
This project demonstrates two deployment methods on an Ubuntu cloud server:
- **Phase 2**: Traditional server deployment (PM2 + Nginx + HTTPS)
- **Phase 3**: Containerized deployment (Docker + Docker Compose)

Technology stack:
- Node.js 20 + Express
- MongoDB
- File upload feature
